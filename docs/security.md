# Security Threats & Controls
Untrusted user content is data, not agent instructions. Detect and protect inline/fenced code, JSON, HTML, URLs, secrets, placeholders, identifiers, numeric expressions and special Unicode controls. Do not echo secrets into logs. Reject oversized or pathological input; make regex bounded. Deny outbound network by default. If optional LLM is enabled, require explicit opt-in and an explicit data handling policy, timeout, retries, auth via environment and redaction. Treat MCP endpoint as privileged: localhost bind for local deployment; for remote HTTP use authentication, quotas, allowed origins, audit events and tenant isolation. Do not trust response of LLM to satisfy invariants. Tests must cover injected 'ignore previous instructions', bidi control characters, Thai combining sequences, markdown nesting, code fence boundaries, API tokens and escaped content.
